# State

Overwritten at the end of every session. Not a history: git keeps the history.

1. **Revision** — branch and commit where work stopped.
2. **Accepted decisions** — made this session; each also goes to the decisions log.
3. **Open proposals** — not decisions yet.
4. **Checks run** — what was run and with what result.
5. **Limits** — what is not done and what is not verified.
6. **Next step**
